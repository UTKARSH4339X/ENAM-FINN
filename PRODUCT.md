# FINN — Merged Product Vision

Personal AI investment copilot for Indian public markets.  
Built for the ENAM challenge now; shaped for Groww/Zerodha-class depth next.

## What we keep from your idea

- Push + Pull intelligence as the core loop
- Personalized financial profile (risk, goals, style, drawdown)
- Portfolio intelligence with **explained** insights
- Decision engine: BUY / HOLD / REDUCE / SELL / AVOID / WAIT + thesis invalidation
- Portfolio Guardian (proactive protection + opportunities)
- Broker integration **architecture** (authorized APIs, never passwords)
- Manual / CSV portfolio path
- Simulated data clearly labeled
- Read-only by default — no silent auto-trading
- Risk sizing + stop rules as **decision support** (paper exit), not broker fire-and-forget

## What we keep from ENAM / current FINN

- Mobile-first product, not a desktop dashboard clone
- “Only what earns the desk” filtering (noise burial)
- Primary-source research discipline (AR + transcripts)
- Filing prioritization + volume/price thresholds
- Thin-but-working beats broad-but-broken

## What we deliberately defer (post-MVP)

- Live Groww / Zerodha order routing
- Full MVO / Black-Litterman / Risk Parity solvers
- LSTM / Transformer price guarantees
- Heavy Tailwind redesign of the whole UI (ship product first)
- Multi-channel notification infrastructure

## MVP cut (what ships now)

1. Onboarding → financial profile
2. Mock broker book (18 NSE names) + simulated badge
3. Digest tape (push) + Ask FINN (pull)
4. Research with fundamentals narrative + **decision card**
5. Risk desk (stop / size / paper auto-exit)
6. Guardian: concentration, drawdown, thesis, opportunities
7. Portfolio intelligence insights on Book

## Trust rules

- Never invent prices or statements
- Always show data as **Simulated demo data** until a live broker is connected
- Every recommendation includes downside + what invalidates it
- Explicit user approval required for any future order submission
